# frontend — React 网页管理端

存放前端代码，面向管理人员：从后端拉取问题列表、查看问题信息、修改处理状态。技术栈固定为 React + TypeScript，构建工具为 Vite。

## 用途

管理端不参与场景与坐标计算，只做问题展示与状态提交。

## 目录说明

| 路径 | 用途 |
| --- | --- |
| `src/api/` | 后端接口调用封装，统一 base URL、超时与错误处理 |
| `src/components/` | 可复用展示组件（列表、状态菜单、详情抽屉、侧边栏、提示条） |
| `src/pages/` | 页面级组件（`DashboardPage` 负责取数与视图编排） |
| `src/lib/` | 纯函数：时间/坐标格式化、统计与筛选，`regions.ts` 定义 5 个固定区域 |
| `src/styles/` | 设计令牌、组件样式与布局样式 |
| `src/types/` | 与后端契约对应的类型定义（Issue、枚举、视图标识） |
| `public/` | 不参与打包编译的静态资源 |

## 命令

```bash
npm install      # 安装依赖
npm run dev      # 本地开发，默认 http://localhost:5173
npm run build    # 类型检查 + 产出 dist/
npm run preview  # 预览构建产物
```

## 环境变量

复制 `.env.example` 为 `.env.local`，按需修改后端地址：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `VITE_API_BASE_URL` | 空（同源） | Go 后端的基址，不含 `/api`；留空时走 Vite 代理 |

`vite.config.ts` 已把 `/api` 代理到 `http://localhost:8080`，因此开发时前端使用相对路径即可，不依赖跨域配置。

## 当前状态

管理端已按 SaaS 后台形态改版：左侧导航 + 顶栏 + 三个视图共用一次 `GET /api/issues`。

- **巡检态势**：待处置计数、已解决率环图、状态/优先级分布、区域负载与最近上报。
- **问题与工单**：状态分段筛选、优先级与区域下拉、全局检索（`Ctrl/Cmd + K`），列表展示标题、优先级、状态、区域与设备编号；状态列只读，修改统一在详情抽屉完成。
- **区域分布**：按 5 个固定区域（泵区 / 储罐区 / 输送区 / 配电区 / 控制区）展示厂区平面图与状态统计，区域内标注上报点，点击区域框或条目跳到该区域工单；框外记录归入「厂区其他」。
- **详情与删除**：右侧抽屉展示完整描述、设备/区域、三轴原始坐标与时间，是状态修改的唯一入口（三态切换），并可删除；删除需二次确认，成功返回 204。
- **异常兜底**：加载中显示骨架屏；后端不可用显示「加载失败」与重试，并给出接口地址与排查提示；渲染期异常由 `ErrorBoundary` 接住，不会白屏。
